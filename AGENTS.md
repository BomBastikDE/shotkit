# Hinweise für KI-Agenten

Vor jeder Arbeit an diesem Repository [CONTRIBUTING.md](CONTRIBUTING.md) lesen und befolgen. Die Regeln dort sind verbindlich, insbesondere:

- nur auf kurzlebigen Branches arbeiten und per Pull Request nach `main`, keine direkten Pushes;
- Releases nur von `main` taggen;
- Sicherheit und `priorität: hoch` vor neuen Funktionen.
